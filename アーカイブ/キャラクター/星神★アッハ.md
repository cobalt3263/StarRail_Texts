<a id="term-a097c63a74f1"></a>

**追加攻撃**

条件を満たした時に自動で発動し、さらにターゲットに攻撃を1回行う。

<a id="term-15e9bc6e10f9"></a>

**追加ターン**

ターン数を消費しない追加ターンを1回獲得する。このターン中、必殺技を割り込ませることはできない。

<a id="term-29a872c6d3ad"></a>

**確定ダメージ**

いかなる効果にも影響されない無属性ダメージ。このダメージは攻撃を1回行ったと見なされない。

<a id="term-5e84bdc9c29b"></a>

**愉悦ダメージ**

カウントされた爆笑ネタが多いほど、愉悦度、キャラのレベルが高いほど、与える愉悦ダメージが高くなる。  
愉悦ダメージはダメージアップ系効果の影響を受けない。

<a id="term-02c0d73b2106"></a>

**アッハ**

行動時にアッハタイムを発動し、愉悦スキルを発動できるユニットがそれぞれ愉悦スキルを1回発動する。アッハの行動時に愉悦スキルを発動できるユニットがいない場合、アッハが「笑いあれ」を発動する。  
アッハタイムは今回の最後の愉悦スキルが発動完了するまで継続。  
アッハタイム終了時、出演したキャラに今回の爆笑ネタがカウントされた「爆笑の褒美」状態を付与する、2ターン継続。アッハが行動した後、すべての爆笑ネタを消費する。

<a id="term-7f81c212ead3"></a>

**爆笑ネタ**

爆笑ネタは味方全体で共有する。愉悦ダメージを与える時、カウントされた爆笑ネタが多いほど、愉悦ダメージがアップする。

<a id="term-e777d1b2cd07"></a>

**爆笑の褒美**

アッハタイムに出演したキャラに「爆笑の褒美」状態を付与し、今回のアッハタイムでの爆笑ネタをこの状態にカウントする、2ターン継続。「爆笑の褒美」状態によるスキル効果と愉悦ダメージはカウントされた爆笑ネタの数で計算される。  
複数の「爆笑の褒美」がある場合、爆笑ネタは合算される。  
各「爆笑の褒美」状態の継続時間は独立で計算される。

<a id="term-e989b09a06c0"></a>

**行動前倒し**

対象の次の行動までの間隔が短くなる。

<a id="term-0877c6f8b6db"></a>

**「愉悦」の運命昇格**

星神★アッハが「愉悦の万象」状態の時、「爆笑ネタ」と「爆笑の褒美」はそれぞれ「爽快ネタ」と「大爆笑の褒美」に強化される。「愉悦」の運命を歩む味方キャラは「固有軌跡」の効果を発動する。

<a id="term-63fdbf103170"></a>

**爽快ネタ**

爽快ネタの獲得は、爆笑ネタの獲得と見なされる。アッハタイム終了時、消費した爽快ネタの一部を再獲得する。

<a id="term-0fdf72d4de79"></a>

**大爆笑の褒美**

「大爆笑の褒美」状態になる時、「爆笑の褒美」状態を獲得したものと見なされる。「大爆笑の褒美」の数値は、「愉悦」の運命を歩む味方キャラの「固有軌跡」に影響を与える。

<a id="term-1da5e3c67332"></a>

**愉悦の負債**

愉悦の負債は最大HPを占有する。占有部分に残りHPが含まれる場合、その分の残りHPは直ちに失われる。

<em>苦しみと笑いの均衡が崩れ、いちばん頼れる大人——均衡の星神『<ruby>互<rp>（</rp><rt>フー</rt><rp>）</rp></ruby>』——がついに動いた！なのに、よりによって誘ったのは、いちばん当てにならないアッハだなんて。</em>  
<em>いったいどういうことなのか、筆者と一緒に見ていきましょう。戦場では愚者と伶人が次々と手品を披露し、世界をすり替えるような奇術を見せるたび、数千万人もの命が救われました。自分で手を下したのか、それとも誰かを働かせたのか？わかる人にはわかるし、わからない人にはわからないってことだね…」</em>

——『第12話：星間エネルギー戦争の知らずにはいられない秘密…』

…  
<em>「裏の歴史によるとね、アッハは星神として働いていた間に、同僚たちから総合評価で堂々の星1をもらったんだって。だから『星神★アッハ』って呼ばれてるんだよ！」</em> 漫画家が言う。  
<em>「だから…あなたの言うアッハって、結局どんな存在なの？」</em> 客席からは、なおも問いかけが絶えない。

**ストーリー・2**

<em>「『アッハ』…」</em> 舞台の上の伶人が、今にも泣き出しそうな顔をする。<em>「初めから、それは死に際にこぼれるため息だったんだよ…」</em>

<em>「そ…それが、其の最初の死だったんだ…」</em>  
伶人は震える声で語る。狂気に堕ちた悪獣が、生まれたばかりの神を追い立てていた。両者は星の河を越え、深淵を渡り、星の光さえも獣の口の中へと消えていく。  
果てしない追跡と逃走の末、アッハは「樹」によじ登った。そして、もう後がなくなったところで、悪獣にひと口で頭を食いちぎられた。  
<em>「痛い…痛いよ…アッハなんて、なりたい人がなればいいじゃん…」</em>  
伶人の真に迫った演技に、観客たちは大笑いした。だが、その目が本当に赤くなっていることには、誰も気づかなかった。

<em>「それから、愉悦の葬儀は果てしなく続き、腐臭に満ちていったんだ…」</em>  
安楽と享楽に満ちた空気の中、ドーパミン、ドーパミン、またドーパミン。やがて、ありふれた芸では欲望を満たせなくなり、甘やかされた神経が、さらなる刺激を求めはじめる——  
<em>「『愉悦』がなんたるかを決めるのは、我々だ！」</em>  
一線を越えた茶番劇が銀河の至る所で繰り広げられ、観客は他人の苦痛さえ見世物にして愉しんだ。愉悦の信奉者たちは、ゴミを捨てるように銀河へ笑い話を垂れ流した。

しかし、人々はアッハの死を信じず、むしろ其の空っぽの殻に、思い思いの姿を重ねていった。  
「混沌」「つかみどころがない」「邪悪」「いたずら好き」「気前がいい」「ケチ」…そうして、気まぐれで、互いに矛盾する無数のアッハが、次々と舞台に現れる——それは、あの悪獣にどこか似ていた。  
ならば、仮面の下のアッハはいったいどこにいる？

首を失った神の身体を見つめ、伶人は雨のように涙を流した。  
<em>「こうして、こうしてね…命はいつも泣き声の中で終わりを迎えて、また新しい命の産声を聞くんだ。なんて脆くて、なんて悲しくて、なんて…おめでたいことなんだろうね…」</em>

**ストーリー・3**

<em>「いいことじゃない。どうしてまた泣いてるの？」</em> 愚者はティッシュを差し出し、愉しげに笑い続ける——  
<em>「あたしに言わせれば、本当の『アッハ』は、人間と一緒に上げる笑い声なんだよ！」</em>

最初の笑い声を上げたのは、伶人に拾われた赤ん坊だった。どうやら、彼女は生まれながらのいたずらの天才らしい。  
それ以来、厳粛だった劇団に安らかな日はなくなった。哀歌は舞曲に書き換えられ、六弦琴はねじり揚げ菓子になり、ゴンドラにはスイーツが山積みにされた。何しろ、彼女が劇団長になってしまったのだから。  
劇団長は可笑しな船の<ruby>舳先<rp>（</rp><rt>へさき</rt><rp>）</rp></ruby>に座り、笑って言った。<em>「キミたちの物語を聞かせてよ。もしかしたら、アッハを泣かせられるかもね？」</em>  
こうして、8人の伶人がビスケットのような月の下、輪になって座った。彼女はたったひとつの語り出しを餌に、長く素晴らしい物語を数えきれないほど釣り上げた。

彼女が豊穣の枝を折り取ると、笑いが根を張り、芽吹いた。幾世代もの請謁者たちが、幻月遊儀に奇跡を捧げていった。  
だが、笑いの神様に謁見できるのは勝者だけではない。彼女はいつだって、笑い声のするあらゆる場所に隠れている。  
空の向こうに憧れる女の子には「開拓」の明けの明星を残し、「豊穣」に迷う少女には仮面を届け、「虚無」に溺れる人々のために黒い太陽を追い払う…投資に回すはずだった運は、きっと全部そっちに使ってしまったに違いない！

<em>「アッハ、凡人とつるんでばかりでは、いずれお前も同類になるぞ」</em>  
かつて、同僚からそう忠告されたことがある。彼女はそれを、褒め言葉として受け取った——  
<em>「おとなしく自分の運命を演じてるだけなんて、それのどこが笑いの神様なわけ？」</em>  
だが、長い時が流れ、「欲望」が「愉悦」を蝕んでいくうちに、彼女もすっかり疲れ果ててしまった。  
蘇った悪獣を前に、彼女は迷う。自分が舞台に上がった時、待っているのは困惑か、白けた沈黙か、それとも拍手か。

彼女はこのまま舞台裏に隠れているつもりだった。だが、ふと気づけば、かつて自ら蒔いた願いはすでに芽吹いていた。  
列車のライトが再びその瞳を照らした時、彼女はいても立ってもいられずホームで待ち受け、新しい世界で最初の、とびきりの爆笑ネタをお見舞いした——  
<em>「皆さん、こんにちは。二次元シティへようこそ！」</em>

**ストーリー・4**

<em>「これでアッハのすべてだって、思ってない？」</em> 漫画家が観客にウインクする。  
<em>「まさか！最高のジョークに、終わりなんてないんだから！」</em> 愚者が陽気に歌い上げ、照明が集まる。  
<em>「星神の最も厳しい母、すべての愉悦の始まり——」</em> 伶人は涙を拭い、頭上の幻月を仰ぐ。  
伶人、愚者、漫画家が次々と終演の挨拶をすると、舞台には、ぼんやりと見覚えのある人影だけが残った——  
<em>「やあ、古き友よ。来たよ～」</em>

さあ、あたしと一緒に黄昏の時へ戻ろう！星の河に響く古獣の咆哮を聞いて、知性の種たちが影の中を逃げ惑う姿を見てごらん。  
塵ほどにちっぽけな人間たちは、明日をも知れない命。けれど、英雄たちが野生の馬のように駆け抜ける時代でもあったんだ。  
アキヴィリの列車は流星のように銀河を横切り、あたしたちは獣の口にずらりと並ぶ鋭い牙を蹴って、大笑いしながら飛び越えていった——

好敵手を、暇つぶしの遊戯を、勝敗を問わない結末を求める。  
愉快な笑いを、とんでもない勘違いを、美しい調べを求める。  
あたしが「愉悦」を探してるんじゃない。「愉悦」が、あたしの後をついてくるんだよ！

あの頃の神々は、まだみんな若かった。今みたいに心が麻痺してもいなかったし、黙り込んでもいなかったんだ。  
あたしたちは銀河の果てを目指してひた走った。けれど最後には、アキヴィリは宇宙の境界でちっぽけな光の点になって消えて、あたしも首のない神になった。  
銀河は再び静まり返った。でも、あたしたちが残した火種は、今も野を焼き尽くす大火となる時を待ってるんだよ。

今、あたしたちは一緒に舞台に立つ。1000琥珀紀前、すべてが始まったあの時のように。  
<em>「あたしのどんな一面も、歩んできたどんな一歩も、全部あたしだよ。でも、それだけじゃあたしのすべてにはならないんだ」</em>  
伶人、愚者、漫画家は互いに抱き合い、ため息をつき、涙を流し、感嘆し、笑い合う…彼女たちは最初の「アッハ」へと歩み寄り、最後の「アッハ」となった。  
<em>「この前代未聞の幻月遊儀で、あたしもキミと一緒に、前代未聞の奇跡を捧げちゃおう！」</em>  
満月が昇る。請謁者たちは幕を開け、笑顔で舞台へと歩み出るだろう。

<em>「ねえ、古き友よ。答えは見つかった？しーっ、見つからなくてもいいんだよ。大切なのは、何かを証明することじゃないんだから」</em>  
これで自己紹介はおしまい。ここに、あたし——アッハから、銀河のみんなに招待状を送るよ——  
<em>「さあ、思いっきり騒いで、幕を開けよう——この最後の即興芝居を！」</em>
