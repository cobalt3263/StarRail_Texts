**固定確率**

**行動制限系デバフ**

凍結、もつれ、禁錮、支配、怒噪、強烈震とう、異夢、縛り、恐怖、行動ロック、幸福傀儡、身を焼く怨炎。

<a id="term-15e9bc6e10f9"></a>

**追加ターン**

ターン数を消費しない追加ターンを1回獲得する。このターン中、必殺技を割り込ませることはできない。

<a id="term-953a383d4bbe"></a>

**バフ**

戦闘に有益な効果をもたらす持続状態。特殊な説明がない限り解除可能。

<a id="term-29a872c6d3ad"></a>

**確定ダメージ**

いかなる効果にも影響されない無属性ダメージ。このダメージは攻撃を1回行ったと見なされない。

<a id="term-7f81c212ead3"></a>

**爆笑ネタ**

爆笑ネタは味方全体で共有する。愉悦ダメージを与える時、カウントされた爆笑ネタが多いほど、愉悦ダメージがアップする。

<a id="term-5ad304cd5bb7"></a>

**爆笑の褒美**

アッハタイムに出演したキャラに「爆笑の褒美」状態を付与し、今回のアッハタイムでの爆笑ネタをこの状態にカウントする、2ターン継続。「爆笑の褒美」状態によるスキル効果と愉悦ダメージはカウントされた爆笑ネタの数で計算される。  
複数の「爆笑の褒美」がある場合、爆笑ネタは合算される。  
各「爆笑の褒美」状態の継続時間は独立で計算される。

<a id="term-40ce553c91bf"></a>

**愉悦ダメージ**

カウントされた爆笑ネタが多いほど、愉悦度、キャラのレベルが高いほど、与える愉悦ダメージが高くなる。  
愉悦ダメージはダメージアップ系効果の影響を受けない。

<a id="term-f97eada9bd63"></a>

**SSSサプライボックス**

「銀狼LV.999」が「爆笑の褒美」を所持している時に、「銀狼LV.999」の結界内にいる味方が発動できる特殊攻撃。この攻撃は、ボーナスステージ「ウルフロードタイム」中でも発動でき、この方法で発動した場合は攻撃を1回行ったとみなされない。  
発動時、大量の虚数属性の愉悦ダメージを与え、敵全体が均等に分担する。同時に、以下の3種類の効果のうちのランダムな1種類が発動する。  
「スーパー・グレートソード」：残りHPが最も高い敵に対し、今回の総ダメージに基づく確定ダメージを与える。  
「ウルトラ・エッグボンバー」：SPを回復する（SPが少ない場合は発動確率が上がり、SPが多い場合は発動確率が下がる）。  
「ストレンジ・ビーン」：爆笑ネタを獲得する（「シークレットスコア」が少ない場合は発動確率が上がり、「シークレットスコア」が多い場合は発動確率が下がる）。
