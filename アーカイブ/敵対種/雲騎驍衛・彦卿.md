<a id="enemy-term-4ac9a0693188"></a>

**速度**

速度は、ユニットの2回の行動の間隔に影響する。速度値が高いほど、間隔は短くなる。  
速度は、戦闘に入る時の行動順にも影響する。

<a id="enemy-term-5bc116f7d032"></a>

**剣陣**

彦卿の靭性が削られなくなる。すべての「飛剣」を倒すとこの効果が解除され、彦卿はダメージを受ける。

彦卿の靭性が削られなくなる。任意の「飛剣」を倒すとこの効果が解除され、彦卿の靭性が削られる。

**別の状態説明**

彦卿の靭性が削られなくなり、速度+<span style="color: #f29e38ff;" markdown="span">○○</span>。すべての「飛剣」を倒すとこの効果が解除され、彦卿はダメージを受ける。

<a id="enemy-term-475ade6c2e43"></a>

**陣眼**

この敵の弱点属性は風、雷、虚数のうちの一つ。正確な属性の攻撃を当てると、弱点属性が明らかになる。弱点撃破されると、この敵は消滅する。

<a id="enemy-term-a4eb0c630b17"></a>

**ロックオン**

<span style="color: #f29e38ff;" markdown="span">雲騎驍衛・彦卿</span>に「風帰りて雲動き、天河瀉りし夢」の発動ターゲットとしてロックオンされる。

<a id="enemy-term-68541fc17fdd"></a>

**凍結**

一定ターンの間行動できない。ターンが回ってくるたびに、さらに氷属性付加ダメージを受ける。

## ストーリー

景元将軍の護衛を務める、まだ総角の歳の剣の天才。

**歳陽に取り憑かれた彦卿**

- クエスト「剣の精」

歳陽熔炬に取り憑かれた剣士彦卿。

**熔炬の幻影**

- クエスト「剣の精」

歳陽熔炬が彦卿の剣法を真似て形作った幻影。

**雲騎驍衛・彦卿（スペック） / 厳しい彦卿師匠（本気モード）**

コードが影響を受けた後の正常な投影。参照元の本体は景元将軍の護衛を務める、まだ総角の歳の剣の天才。

**<ruby>雲騎驍衛<rp>（</rp><rt>うんきぎょうえい</rt><rp>）</rp></ruby>・<ruby>彦卿<rp>（</rp><rt>げんきょう</rt><rp>）</rp></ruby>**

景元将軍の護衛であり、まだ総角の歳に過ぎない剣の天才。

**雲騎驍衛・彦卿（幻像）**

景元将軍の護衛を務める、まだ総角の歳の剣の天才。ここに現れたのはあなたの記憶をもとにシミュレートされた幻である。
