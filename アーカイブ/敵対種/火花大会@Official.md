<a id="enemy-term-15e9bc6e10f9"></a>

**追加ターン**

ターン数を消費しない追加ターンを1回獲得する。このターン中、必殺技を割り込ませることはできない。

<a id="enemy-term-acddd2e3a3f6"></a>

**戦闘不能状態**

味方の残りHPが0になるとこの特殊状態に入る。この状態のキャラは戦闘を続けることができない。

<a id="enemy-term-8ac3fc875aaa"></a>

**行動制限系デバフ**

凍結、もつれ、禁錮、支配、怒噪、強烈震とう、異夢、縛り、恐怖、行動ロック、幸福傀儡、身を焼く怨炎。

<a id="enemy-term-7b79b3212cd6"></a>

**視聴者殺到**

行動順が早まり、会心率+<span style="color: #f29e38ff;" markdown="span">○○%</span>。

<a id="enemy-term-689473da69af"></a>

**コラボ対決**

味方全体は<span style="color: #f29e38ff;" markdown="span">メインフィールドとサブフィールド</span>で戦闘を行う。アッハタイム以外では、異なるフィールドにいる味方と敵は、もう一方のフィールドにいるターゲットを<span style="color: #f29e38ff;" markdown="span">攻撃できない</span>。アッハタイムの間、愉悦スキルは<span style="color: #f29e38ff;" markdown="span">サブフィールド</span>の敵にのみ発動できる。  
コラボ対決のカウントダウンが終了する時、サブフィールドにいる味方キャラが戦闘不能状態になる時、サブフィールドにいる敵がすべて倒される時、またはサブフィールドにいる戦える味方キャラがいない時、コラボ対決を解除する。

<a id="enemy-term-343c0b0a71ee"></a>

**アッハ**

行動時にアッハタイムを発動し、愉悦スキルを発動できるユニットがそれぞれ愉悦スキルを1回発動する。アッハの行動時に愉悦スキルを発動できるユニットがいない場合、アッハが「笑いあれ」を発動する。  
アッハタイムは今回の最後の愉悦スキルが発動完了するまで継続。  
アッハタイム終了時、出演したキャラに今回の爆笑ネタがカウントされた「爆笑の褒美」状態を付与する、2ターン継続。アッハが行動した後、すべての爆笑ネタを消費する。

<a id="enemy-term-7f81c212ead3"></a>

**爆笑ネタ**

爆笑ネタは味方全体で共有する。愉悦ダメージを与える時、カウントされた爆笑ネタが多いほど、愉悦ダメージがアップする。

<a id="enemy-term-3650b15ce535"></a>

**ランダムな弾幕ペナルティ**

「攻撃力ダウン」、「防御力ダウン」、「速度ダウン」、「虚弱」、「もつれ」状態のいずれかをランダムで付与する。
