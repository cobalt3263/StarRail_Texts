<a id="enemy-term-4ac9a0693188"></a>

**速度**

速度は、ユニットの2回の行動の間隔に影響する。速度値が高いほど、間隔は短くなる。  
速度は、戦闘に入る時の行動順にも影響する。

<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-7f8f6a7032d4"></a>

**侵蝕**

攻撃を行った後、侵蝕に削がれた分のHPを回復する。命中した敵が多いほど、回復量がアップする。ダメージを受けた時、減少したHPの一部が侵蝕に変換される。HPを消費すると失ったHPはすべて侵蝕に変換される。HP回復で侵蝕が解除されると、自身が「新生」効果を獲得する。「新生」：次の攻撃の与ダメージがアップする。

<a id="enemy-term-d3e6c99b11b1"></a>

**血罪の腐蝕**

ターンが回ってきた時、固定の虚数属性ダメージを受ける。

<a id="enemy-term-29a872c6d3ad"></a>

**確定ダメージ**

いかなる効果にも影響されない無属性ダメージ。このダメージは攻撃を1回行ったと見なされない。

<a id="enemy-term-56f8e2d5a0d2"></a>

**壁反震**

自身の靭性を削る。この効果によって靭性値が1未満になることはない。

<a id="enemy-term-085f5fa611ef"></a>

**一体化**

HPが0になるダメージを受ける時、「仮死」状態になる。「一体化」を持つ「黄金の血の記憶の精霊」がすべて「仮死」状態になった時、それらは融合して再び「迷いの淵の裁定者」になる。

<a id="enemy-term-c0c66bc535b9"></a>

**仮死**

ターゲットとして選択できない。行動もできない。
