<a id="enemy-term-4ac9a0693188"></a>

**速度**

速度は、ユニットの2回の行動の間隔に影響する。速度値が高いほど、間隔は短くなる。  
速度は、戦闘に入る時の行動順にも影響する。

<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-8ac3fc875aaa"></a>

**行動制限系デバフ**

凍結、もつれ、禁錮、支配、怒噪、強烈震とう、異夢、縛り、恐怖、行動ロック、幸福傀儡、身を焼く怨炎。

<a id="enemy-term-ffc22c562019"></a>

**宴荒らしの罪**

一定ターンの間、ターンが回ってくるたびに風属性ダメージを受ける。この効果は累積できる。

<a id="enemy-term-bd85e29105f9"></a>

**宴の罪**

一定ターンの間、ターンが回ってくるたびに雷属性ダメージを受ける。この効果は累積できる。

<a id="enemy-term-3cca7b762d02"></a>

**異夢**

一定ターンの間、行動不能になる。また、ターンが回って来るたびに少量のHPを回復する。攻撃を受ける時、被ダメージが大アップし、攻撃を受けた後に「異夢」状態が解除される。

<a id="enemy-term-5a5bd765edc3"></a>

**「秩序の傀儡」**

秩序に操られている傀儡。「司律」になる可能性がある。

<a id="enemy-term-028a5b756823"></a>

**司律**

ターンが回ってくるたびに再行動でき、速度が小幅アップする。

スウィート・ドリーム劇団の役者たちは「秩序」の恩恵を受け、掟を宣明する傀儡と化した。彼らは至高なる戒めのもと、楽園を迎える演目を披露している。
