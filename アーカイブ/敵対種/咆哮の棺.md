<a id="enemy-term-1b7e55a21264"></a>

**月狂い**

この状態では咆哮の棺の速度がアップし、「合成狼毒」と「殺戮アルゴリズム」を発動するようになる。咆哮の棺が弱点撃破される時、この状態は解除される。

<a id="enemy-term-cc8c30eae9eb"></a>

**まとわりつく恐怖**

2ターン目が回ってきた時に「恐怖」状態に陥る。その前にデバフ付与者に攻撃を1回行うと「まとわりつく恐怖」状態を解除できる。

<a id="enemy-term-9ed53a466208"></a>

**恐怖**

行動できない。次のターンが回ってきた時まで継続。

<a id="enemy-term-40873cc2793c"></a>

**嗜血**

「月狂い」状態に入れるすべての敵は「嗜血」の層数を共有する。「月狂い」状態に入れる敵が戦闘に入る時、同等層数の「嗜血」をその敵に付与する。ターン終了時、フィールド上の「月狂い」状態に入れる敵がすべて倒されている場合、「嗜血」の層数をクリアする。

<a id="enemy-term-4d9318123337"></a>

**「月狂い」状態に入れる敵**

「月狂い」状態に入れる敵：狼兵・玄爪、狼兵・蝕月、咆哮の棺、咆哮の棺（バグ）、歩離人の戦首・呼雷、歩離人の戦首・呼雷（スペック）。

## ストーリー

博識学会が研究開発した戦闘兵器。歩離人の生物組織をパーツとしており、長命種の強い生命力と長い歳月で進化した「殺戮アルゴリズム」を併せ持つ。

**咆哮の棺（バグ）**

コードが影響を受けた後、バグってしまった投影。参照元の本体は博識学会が研究開発した戦闘兵器。歩離人の生物組織をパーツとしており、長命種の強い生命力と長い歳月で進化した「殺戮アルゴリズム」を併せ持つ。
