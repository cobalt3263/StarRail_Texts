<a id="enemy-term-0c12626f5b2e"></a>

**付加ダメージ**

攻撃を受けたターゲットがさらにダメージを1回受ける。このダメージは攻撃とは見なされない。

<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-034514b0563f"></a>

**絵具**

「パレットクジャク」は「色彩」状態でスキルを発動する時、「絵具」を消費して対応する属性の付加ダメージを与える。属性ごとに対応する「絵具」は1種類ずつある。

<a id="enemy-term-55e403655d07"></a>

**無色**

味方からの攻撃を受けた後、攻撃者の属性に応じて「絵具」を1獲得する。その攻撃で愉悦ダメージを受けた場合、さらに一定数の「絵具」を獲得する。「絵具」が6に達する時、「色彩」状態になり、獲得した「絵具」の種類に応じて、対応する属性の弱点を付与され、対応する属性耐性がダウンする。「無色」状態の時、靭性は1を下回らない。

<a id="enemy-term-40ce553c91bf"></a>

**愉悦ダメージ**

カウントされた爆笑ネタが多いほど、愉悦度、キャラのレベルが高いほど、与える愉悦ダメージが高くなる。  
愉悦ダメージはダメージアップ系効果の影響を受けない。

<a id="enemy-term-8def39d8b82e"></a>

**色彩**

スキル発動時、「絵具」を消費して対応する属性の付加ダメージを与える。ターン終了時にすべての「絵具」を消費している場合、「無色」状態になり、「絵具」による弱点と属性耐性ダウン効果を解除する。弱点撃破された時、「絵具」をすべて消費し、自身に最大HP一定割合分の付加ダメージを与える。

<a id="enemy-term-7f81c212ead3"></a>

**爆笑ネタ**

爆笑ネタは味方全体で共有する。愉悦ダメージを与える時、カウントされた爆笑ネタが多いほど、愉悦ダメージがアップする。
