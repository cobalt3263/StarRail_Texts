<a id="enemy-term-4910b6742865"></a>

**バリア**

持続ダメージ以外のすべてのダメージを防ぐ。この効果は攻撃を受けた後に解除される。

<a id="enemy-term-f3208d90c429"></a>

**カウンター**

対象が攻撃を受けた後に自動で効果を発動する。攻撃者に対し、さらに攻撃を1回行う。  
カウンターも追加攻撃と見なされる。

<a id="enemy-term-4ac9a0693188"></a>

**速度**

速度は、ユニットの2回の行動の間隔に影響する。速度値が高いほど、間隔は短くなる。  
速度は、戦闘に入る時の行動順にも影響する。

<a id="enemy-term-acddd2e3a3f6"></a>

**戦闘不能状態**

味方の残りHPが0になるとこの特殊状態に入る。この状態のキャラは戦闘を続けることができない。

<a id="enemy-term-68541fc17fdd"></a>

**凍結**

一定ターンの間行動できない。ターンが回ってくるたびに、さらに氷属性付加ダメージを受ける。

## ストーリー

シルバーメインの戍衛官。  
ジェパードは麾下の兵士に集中攻撃を仕掛けるよう命令する。同時に、兵士に攻撃を1回無効化できるバリアを付与する。
