### スキル

**オートマジカルステッキ**

| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | パチパチ魔弾 | 指定した味方単体に量子属性ダメージを与える。 |
| スキル | 幸福の呪文 | ランダムで以下の効果が1つ発動する。自身の[攻撃力アップ](#enemy-term-b1b12faf5fee)、敵全体の[行動前倒し](#enemy-term-e989b09a06c0)、高確率で自身以外の敵全体に「[強烈震とう](#enemy-term-57db0fa5ea05)」を付与する。 |
| 天賦 | 笑顔の魔法 | 自身が初めて攻撃を受けた時、味方は<ins>[爆笑ネタ](#enemy-term-7f81c212ead3)</ins>を獲得する。同時に「幸福の呪文」を発動する。 |

<a id="enemy-term-e989b09a06c0"></a>

**行動前倒し**

対象の次の行動までの間隔が短くなる。

<a id="enemy-term-57db0fa5ea05"></a>

**強烈震とう**

行動順が遅延され、一定ターンの間行動不能。

<a id="enemy-term-7f81c212ead3"></a>

**爆笑ネタ**

爆笑ネタは味方全体で共有する。愉悦ダメージを与える時、カウントされた爆笑ネタが多いほど、愉悦ダメージがアップする。

<a id="enemy-term-b1b12faf5fee"></a>

**攻撃力アップ**

1層につき、攻撃力+<span style="color: #f29e38ff;" markdown="span">○○%</span>。
