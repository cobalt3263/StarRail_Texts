<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-0c12626f5b2e"></a>

**付加ダメージ**

攻撃を受けたターゲットがさらにダメージを1回受ける。このダメージは攻撃とは見なされない。

<a id="enemy-term-acddd2e3a3f6"></a>

**戦闘不能状態**

味方の残りHPが0になるとこの特殊状態に入る。この状態のキャラは戦闘を続けることができない。

<a id="enemy-term-7979266003b8"></a>

**均等に分担**

今回の攻撃決算前のダメージとデバフ効果は、攻撃を受けたすべてのターゲットが均等に分担する。

<a id="enemy-term-29a872c6d3ad"></a>

**確定ダメージ**

いかなる効果にも影響されない無属性ダメージ。このダメージは攻撃を1回行ったと見なされない。

<a id="enemy-term-65da8af8b37e"></a>

**非致死性**

ターゲットがダメージを受けた時、自身のHPが足りない場合、残りHPが1になる。

<a id="enemy-term-9b4fbe6f2342"></a>

**温度**

現在の戦場の環境温度に応じて、味方は持続的に燃焼ダメージを受ける。味方の与ダメージは温度に応じてアップする。

<a id="enemy-term-87babd987853"></a>

**修復**

指定した敵の行動制限系デバフと弱点撃破状態を解除する。指定した敵がターゲットとして選択できない状態の場合、その敵を選択可能な状態にする。

<a id="enemy-term-e5869513499f"></a>

**ヘリウムフラッシュ**

「至高、極陽、天空の化身」が「怒り、晨昏と日星を焼く」を発動した後、現在の「ヘリウムフラッシュ」に応じて「温度」が上がる。この状態で味方が攻撃を行った後、その回の攻撃が命中した敵の数に応じて「ヘリウムフラッシュ」をダウンさせる。

<a id="enemy-term-182c122d53e8"></a>

**雷雲**

現在の戦場環境で雷雲が蓄積される。「至高、極陽、天空の化身」が「憤り、昼夜の天空を破る」を発動した後、「雷雲」の層数に応じた回数分、味方に少量の雷属性ダメージを与える。その後、味方が奪い取った「雷雲」の数に応じて、自身に少量の雷属性ダメージを与える。

<a id="enemy-term-e982db7de562"></a>

**電離**

この時、味方が攻撃を行うと、その攻撃が命中した敵の数に応じて「雷雲」を奪う。「陽雷の鴉」、「百眼の芽」、または「百眼の梢」がHPが0になる攻撃を受けた場合、さらに「雷雲」を一定量奪う。なお、すべての「雷雲」が奪われると敵は弱点撃破状態に陥る。

<a id="enemy-term-715d04679734"></a>

**腐敗**

回復できる最大HPがダウンする。

<a id="enemy-term-9e91dd957165"></a>

**黒蝕**

「黒蝕」状態では、ターゲットとして選択できない。行動もできない。

## ストーリー

「天空」のタイタンであり、融合神。人に征服され、人と融合したことで、オンパロスの昼夜を支配する存在ではなくなった。だが、その孤高で傲慢な本性は変わっていない。  
その目に映る壊れた世界の俗世はかくも醜く——光で守られた世界よりも暗黒の潮のほうが相応しいとさえ言える。

**絶滅者、陽雷の業果、晨昏の目**

- クエスト「詩人よ、天空を語れ・下」

覇道をもって天空を統べていた征服者が、暗黒の潮に呑まれた後の姿。かの者の功罪を判断するのは難しいが、今あるのはただ万物を焼き尽くす、滅びの業火のごとき殺意のみ。

**晨昏の目、ヒアシンシア**

- クエスト「英雄よ、灼熱の太陽を最初に灯せ」

微笑みで晨昏を繕う半神が暗黒の潮に呑まれた姿。火種の光は濁っているが、まだ微かな温もりが残っている——  
医師は共に歩んだ友を滅ぼそうとしているのではない。ただ、その心に渦巻く暗雲を払おうとしているのだ。
