## 情報

- 所属：裂界造物
- 弱点：炎 / 氷 / 虚数

### 形態名

- ストーム
- ストーム（バグ）

### スキル

**ストーム**

| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | 風を巡る光隕 | 指定した味方単体に風属性ダメージを与え、高確率で[風化](#enemy-term-473ac56bc036)状態にする。 |
| スキル | 踏風の行軍 | 指定した味方単体および隣接する味方に少量の風属性ダメージを与え、確率で攻撃を受けた味方を[風化](#enemy-term-473ac56bc036)状態にする。 |
| スキル | 風を掴む | チャージ状態に入り、[風化](#enemy-term-473ac56bc036)状態にあるすべての味方を[ロックオン](#enemy-term-490da05b243c)し、次の行動で「暴風の矢」を発動する。 |
| スキル | 暴風の矢 | [風化](#enemy-term-473ac56bc036)状態の味方に風属性ダメージを与える。フィールド上に[風化](#enemy-term-473ac56bc036)状態の味方が存在しない場合、このスキルの発動は失敗する。 |
| 天賦 | 急旋する風 | [風化](#enemy-term-473ac56bc036)状態の味方を攻撃した後、攻撃力が小アップする。弱点撃破されると効果が解除される。 |

**風化**

一定ターンの間、ターンが回ってくるたびに風属性ダメージを受ける。この状態は累積できる。

## ストーリー

裂界拡大の途中で侵蝕されたモンスター、力の源が変異した後、より柔軟な戦闘スタイルを得た。  
ストームは風の力を利用して戦いを有利に進め、追い風に乗った迅速な矢を放つ。

**ストーム（バグ）**

コードが影響を受けた後、バグってしまった投影。裂界拡大の途中で侵蝕されたモンスターを参考にしている。力の源が変異した後、より柔軟な戦闘スタイルを得た。  
ストームは風の力を利用して戦いを有利に進め、追い風に乗った迅速な矢を放つ。そして戦闘中に風の造物を召喚し、共に戦う。
