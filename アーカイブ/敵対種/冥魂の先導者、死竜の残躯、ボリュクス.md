**行動遅延**

対象の次の行動までの間隔が長くなる。

<a id="enemy-term-339b756b1c01"></a>

**持続ダメージ系デバフ**

裂創、燃焼、感電、風化。

<a id="enemy-term-7979266003b8"></a>

**均等に分担**

今回の攻撃決算前のダメージとデバフ効果は、攻撃を受けたすべてのターゲットが均等に分担する。

<a id="enemy-term-1fc5bb73302b"></a>

**衰亡ダメージ**

バリアで防げず、分担不能の固定ダメージを与える。

<a id="enemy-term-adbda0f3a7df"></a>

**死の芳香**

ターンが終了するたびに、自身の速度がアップする。「ボリュクス」または「憐憫の腕」が攻撃を受けると「死へと誘う泡」が削られ、味方のHPが回復する。「死へと誘う泡」が0になるとこの状態が解除される。

<a id="enemy-term-65da8af8b37e"></a>

**非致死性**

ターゲットがダメージを受けた時、自身のHPが足りない場合、残りHPが1になる。

<a id="enemy-term-fae1ea7703e9"></a>

**永遠の眠りの中**

このターゲットが敵にダメージを与えた時、敵の受けるダメージがダウンする。味方のHPが一定まで回復すると、この状態を解除できる。

**弱点撃破効率**

弱点撃破効率が高いほど、靭性に対するダメージが上がる。

<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-8efe0d9bcd7a"></a>

**耐負荷**

ターゲットのHPは1を下回らない。受けるダメージの残りHPを超えた分は<ins>「負荷HP」</ins>に変換される。治癒を受けると<ins>「負荷HP」</ins>を優先的に回復する。

<a id="enemy-term-c19b05e658ee"></a>

**瀕死の足掻き**

この味方は一定量の<ins>「負荷HP」</ins>を累積したため、与ダメージと弱点撃破効率が低下し、一定ターン後にHPが0になるダメージを受ける。

<a id="enemy-term-e100a0fd357f"></a>

**腐敗の咬傷**

このターゲットを攻撃した後、攻撃者は少量の量子属性の<ins>「衰亡ダメージ」</ins>を受ける。

## ストーリー

ステュクスに眠る死竜は、錬成により再び目を覚まし、腐肉を纏う朽ちた骨と化す。  
かつて「死」のタイタンだった死竜はステュクスの流れに逆らい、夢現の境を離れ、現世に座礁する。それはかつてステュクスの潮汐と共に大地に湧き、オンパロスの万物に運命の結末を刻んだ。死にかけの者も、死んだ者も、その帰還によって魂の奥底が震えることとなる。

**冥魂の先導者、死竜の残躯、ボリュクス（スペック）**

コードが影響を受けた後の正常な投影。ステュクスに眠る死竜は錬成により再び目を覚まし、腐肉を纏う朽ちた骸と化す。  
かつて「死」のタイタンだった死竜はステュクスの流れに逆らい、夢現の境を離れ、現世に漂着した。それはかつてステュクスの潮汐と共に大地に湧き、オンパロスの万物に運命の結末を刻んだ。死にかけの者も、死んだ者も、その帰還によって魂の奥底が震えることとなる。

**冥魂の先導者、死竜の残躯、ボリュクス（汚染）**

かつて「死」のタイタンだった死竜はステュクスの流れに逆らい、夢現の境を離れ、現世に座礁した。そしてステュクスの潮汐と共に大地に湧き上がり、オンパロスの万物に運命の結末を刻み込んだのだ。死に瀕する者も、すでに死した者も、その帰還によって魂の奥底を震わせることになるだろう。

**枯れ果てた導き手**

かつて「死」のタイタンであった死竜はステュクスの流れに逆らって夢現の境を離れ、現世に座礁した。そしてステュクスの満ち引きと共に大地に湧き上がり、オンパロスの万物に運命の結末を刻みつける。死に瀕する者も、すでに死した者も、その帰還によって魂の奥底を震わせることになるだろう。
