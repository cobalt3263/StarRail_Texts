<a id="enemy-term-61c33cd4916c"></a>

**発砲**

ターゲットにダメージを与える。「発砲」する回数が多いほど、ダメージ倍率がアップする。

<a id="enemy-term-020622740a2a"></a>

**暴発**

敵が暴発した時、敵にダメージを与える。発砲回数が多いほど、暴発する確率が高くなり、暴発のダメージ倍率も高くなる。味方が暴発した時、味方のHPを減少させる。発砲回数が多いほど暴発する確率が高くなり、暴発で失うHP倍率も多くなる。このダメージは優先的にバリアを消費する。

<a id="enemy-term-7f81c212ead3"></a>

**爆笑ネタ**

爆笑ネタは味方全体で共有する。愉悦ダメージを与える時、カウントされた爆笑ネタが多いほど、愉悦ダメージがアップする。

<a id="enemy-term-c5b9b2b4ee2e"></a>

**行動制限系デバフ**

凍結、もつれ、禁錮、支配、怒噪、強烈震とう、異夢、縛り、恐怖、行動ロック、幸福傀儡、身を焼く怨炎、麻痺。

<a id="enemy-term-f6a0eb5b108d"></a>

**狂気ネタ**

「『哲学の胎児』 - 狂気」がスキルを発動する時に獲得する。その数が味方の爆笑ネタの数を超えた時、自身の行動順が早まり、「<ins>狂気</ins>」状態に入る。味方の爆笑ネタの数がその数を超えた時、自身の「<ins>狂気</ins>」状態を解除する。

<a id="enemy-term-a21e6e0009b8"></a>

**狂気**

与ダメージがアップし、自身の攻撃を受けたターゲットの回復できる最大HPをダウンさせる。味方の爆笑ネタの数が狂気ネタの数を上回ると解除される。

<a id="enemy-term-cf617917556f"></a>

**愉快**

会心率がアップし、攻撃時に味方全体が「狂気」状態による最大HP低下効果を軽減する。狂気ネタの数が味方の爆笑ネタの数を上回ると解除される。
