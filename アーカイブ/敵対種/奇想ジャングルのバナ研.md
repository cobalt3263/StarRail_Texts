**行動制限系デバフ**

凍結、もつれ、禁錮、支配、怒噪、強烈震とう、異夢、縛り、恐怖、行動ロック、幸福傀儡、身を焼く怨炎。

<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-8d823d8faae0"></a>

**行動遅延**

対象の次の行動までの間隔が長くなる。

<a id="enemy-term-3996c7d4e2a9"></a>

**講義チャンネル**

「バナ研」のメンバーは「講義チャンネル」関連のスキルが使用できる。カウントが上限に達する時、「空きコマチャンネル」状態に切り替わり、弱点撃破状態になる。

<a id="enemy-term-fa1f64a1439c"></a>

**切り替えカウント**

「講義チャンネル」状態の敵が攻撃を受けた後、切り替えカウント+1。切り替えカウントが上限に達する時、「空きコマチャンネル」に切り替わる。

## ストーリー

「源究の森」の茂みに理性を覆われてしまったスウィート・ドリーム劇団。「奇想ジャングル」で発生したミームウイルスを携え、夢の中でバナーネモンキーが代表する精神と、原始博士の教えをバナ暴に宣伝している。

**バナゆいモンキートリック**

「源究の森」の茂みに理性を覆われてしまったスウィート・ドリーム劇団。「奇想ジャングル」で発生したミームウィルスを携帯し、夢の中でバナーネモンキーが表す精神と原始博士の教えをバナ暴に宣伝している。

**奇想ジャングルのバナ研（スペック）**

コードが影響を受けた後の正常な投影。参照元の本体は「源究の森」の茂みに理性を覆われてしまったスウィート・ドリーム劇団。「奇想ジャングル」で発生したミームウイルスを携え、夢の中でバナーネモンキーが代表する精神と、原始博士の教えをバナ暴に宣伝している。

**千面相のスコート / 千面相のスコート（汚染）**

- クエスト「Fate / 沈黙の時代への回帰」

すべての撮影リソースを集め、大物の中の大物となった主人公スコート。サーヴァントによって意識と魂を分離された後、千の顔を以って開拓者への復讐の道を歩み始めた。
