| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | 腐敗を反芻する夢 | 指定した味方単体に少量の量子属性ダメージを与える。フィールド上に「[蜃気楼への突撃](#enemy-term-2a234b600cac)」状態の「泡沫の稚児」がいる場合、さらに量子属性ダメージを与える。 |

<a id="enemy-term-b29feddea192"></a>

**壊滅の狂宴**

行動順が早まるまでに必要な被攻撃回数がダウンする。ダメージを受ける、または特定のスキルを発動してダメージを与えた時、そのダメージの一部は即座には発生せず、「暗黒の潮の熱病」の形で一定ターン内に発生する。「壊滅の狂宴」のカウントダウンのターンが回ってきた時、敵全体の「壊滅の狂宴」状態が解除される。

<a id="enemy-term-2a234b600cac"></a>

**蜃気楼への突撃**

「蜃気楼への突撃」状態が解除されるまで、他の「泡沫の稚児」はロックオンされた味方を優先的に攻撃する。自身が弱点撃破されるか、HPが0になる攻撃を受けた時、この状態を解除する。

## ストーリー

海の娘たちは「壊滅」の罪に魂も肉体も蝕まれ、歪な抜け殻だけを残した…今世、彼女たちは虚無に消えゆくことなく、「海洋」の刃に従い、黒き太陽へと襲いかかる荒波となった。  
終末の嵐が天より降り注ぎ、万物の滅亡を告げる——  
不幸にも早産した泡沫は、生まれる前から消え去る運命を背負い、数えきれぬ悲嘆を吐き出す——  
濁った羊水が奔流となり天と地を黒く染め、生まれたばかりの希望さえも穢した。
