## 情報

- 所属：暗黒の潮の造物
- 弱点：物理 / 炎 / 量子

### 形態名

- エクリプスグリフォン

### スキル

**エクリプスグリフォン**

| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | 黒光の貫射 | 味方全体に風属性ダメージを与える。命中した味方の減少したHPの一部が<ins>「[侵蝕](#enemy-term-7f8f6a7032d4)」</ins>に変換される。 |
| スキル | 永夜の布告 | 「エクリプスアーチャー」を召喚する。「エクリプスアーチャー」が倒されると、自身は一定のHPを失う。「エクリプスアーチャー」は自主的に行動しない代わりに、自身が攻撃を行うとそれに追従して攻撃を一回行う。 |
| スキル | 日蝕の預言 | 「[迫る死風](#enemy-term-6f3f5700e6a7)」状態に入り、次の行動で「熱寂の頌歌」を発動する。 |
| スキル | 熱寂の頌歌 | 味方全体に風属性ダメージを与える。この時、味方の<ins>「[侵蝕](#enemy-term-7f8f6a7032d4)」</ins>されたHPが多いほど与えるダメージがアップする。また、<ins>「[侵蝕](#enemy-term-7f8f6a7032d4)」</ins>を受けている分のHPは即座に失われる。 |

<a id="enemy-term-7f8f6a7032d4"></a>

**侵蝕**

攻撃を行った後、侵蝕に削がれた分のHPを回復する。命中した敵が多いほど、回復量がアップする。ダメージを受けた時、減少したHPの一部が侵蝕に変換される。HPを消費すると失ったHPはすべて侵蝕に変換される。HP回復で侵蝕が解除されると、自身が「新生」効果を獲得する。「新生」：次の攻撃の与ダメージがアップする。

<a id="enemy-term-6f3f5700e6a7"></a>

**迫る死風**

次の行動で「熱寂の頌歌」を発動する。

## ストーリー

暗黒の潮に侵蝕されたサンライトグリフォン。虚ろな躯には殺戮への渇望だけが残る。  
エーグルの祝福を失った今、暗黒の潮から得られる無尽蔵のエネルギーが、その存在を恐ろしいものへと変えた。
