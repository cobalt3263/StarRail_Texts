<a id="enemy-term-acddd2e3a3f6"></a>

**戦闘不能状態**

味方の残りHPが0になるとこの特殊状態に入る。この状態のキャラは戦闘を続けることができない。

<a id="enemy-term-7979266003b8"></a>

**均等に分担**

今回の攻撃決算前のダメージとデバフ効果は、攻撃を受けたすべてのターゲットが均等に分担する。

<a id="enemy-term-e30c2f53bbc9"></a>

**記憶の精霊を召喚**

記憶の精霊をフィールドに召喚する。記憶の精霊がフィールド上にいる場合、記憶の精霊に付与されているすべての行動制限系デバフを解除する。

<a id="enemy-term-6b0cd244d737"></a>

**化形**

被ダメージ+<span style="color: #f29e38ff;" markdown="span">○○%</span>。この効果は累積できる。

<a id="enemy-term-8ccb1dd0e8f3"></a>

**潜在能力発現**

与ダメージがアップし、ターンが回ってきた時、HPを回復する。

<a id="enemy-term-c24354cc7e3e"></a>

**二律背反**

必殺技が発動可能になり、発動した時に自身のHPを失う。このダメージはバリアを優先的に消費する。なお、このダメージは非致死性である。効果継続期間中に必殺技を発動しなかった場合、効果が解除された時にEPは元に戻る。

<a id="enemy-term-ce2c4029d789"></a>

**吹き荒れる風**

「吹き荒れる風」效果を持つ相手がターン終了時に即座に行動する。「吹き荒れる風」効果によって発動したターンでは再びこの効果を発動できない。弱点撃破状態になると解除される。
