| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | 薙ぎ払う輝き | 指定した味方単体および隣接する味方に物理属性ダメージを与える。 |

| スキル | 正義の戦線 | 「千星ガード」を召喚する。 |

**行動制限系デバフ**

<a id="enemy-term-2a4d89841e34"></a>

**鼓舞**

**失堕**

受けるダメージ+<span style="color: #f29e38ff;" markdown="span">○○%</span>。

<a id="enemy-term-fece0fff65f8"></a>

**断罪**

次の行動で「悪を断つ」を発動する。

<a id="enemy-term-be40a0beaaf1"></a>

**人々の願い**

「断罪」状態の時、敵全体は「ライトハウス」が持つ「人々の願い」の層数分の「鼓舞」効果を獲得する。

<a id="enemy-term-dca9bd6d2fe7"></a>

**弱点無効**

自身の靭性は削られない。「ライトハウス」の「断罪」状態が解除された時、この効果は解除される。

## ストーリー

千星シティのスーパーヒーロー。博識学会の最先端テクノロジーで武装し、悪を懲らしめ、街の平和を守るために全力を尽くしている。過去5年間にわたって、彼は千星シティの人々を大小さまざまな災難から何度も救ってきた。  
一方で、こうした偉業の数々をたった1人で達成することは不可能だと指摘する者もいる。彼らによれば「ライトハウス」は結局のところエンタメ産業複合体によって生み出された偶像に過ぎないのだという。けれど、自分たちが陥った危機、そのすべてを背負ってくれる誰かを人々が切望していることは間違いない——ただし、「ライトハウス」のアーマーの下に仄暗い秘密が隠されていることに、未だ彼らが気づく様子はない……
