<a id="enemy-term-7f8f6a7032d4"></a>

**侵蝕**

攻撃を行った後、侵蝕に削がれた分のHPを回復する。命中した敵が多いほど、回復量がアップする。ダメージを受けた時、減少したHPの一部が侵蝕に変換される。HPを消費すると失ったHPはすべて侵蝕に変換される。HP回復で侵蝕が解除されると、自身が「新生」効果を獲得する。「新生」：次の攻撃の与ダメージがアップする。

<a id="enemy-term-61e4604c81ff"></a>

**災厄の力**

特定のスキルを発動する時、「災厄の力」の層数を全て消費して攻撃段数を増やす。

<a id="enemy-term-cb504474b5f9"></a>

**沈黙の悲嘆**

次の行動時に「捨つることに涙せず」を発動する。

<a id="enemy-term-fda583bdff0e"></a>

**纏わりつく苦痛**

「壊れた容器」を吸収すると、この「壊れた容器」を召喚した時に消費したHPを回復する。「壊れた容器」が倒されると、「壊れた容器」を召喚した時に消費したHPを回復できなくなる。

<a id="enemy-term-66c78a5f9511"></a>

**枷鎖崩壊**

「最期の嗚咽」と「必要な苦難」を交互に発動する。「最期の嗚咽」は「壊れた容器」を召喚してチャージ状態に入る。「必要な苦難」は強力な攻撃を発動する。「災厄の力」の層数は、強力な攻撃の段数を増やす。「壊れた容器」を倒すことで、靭性と「災厄の力」の層数を削ることができる。第二段階では、「沈黙の悲嘆」と「捨つることに涙せず」を発動し、「災厄の力」の層数がアップする。
