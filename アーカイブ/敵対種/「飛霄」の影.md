<a id="enemy-term-15e9bc6e10f9"></a>

**追加ターン**

ターン数を消費しない追加ターンを1回獲得する。このターン中、必殺技を割り込ませることはできない。

<a id="enemy-term-caf4d00fb34f"></a>

**弱点撃破状態**

敵の靭性が0まで削られた時に入る特殊状態。この状態になった敵は行動順が遅延する。

<a id="enemy-term-9073436cad83"></a>

**虚弱**

与ダメージダウン。

<a id="enemy-term-980cf03e77e4"></a>

**怒噪**

操作不能になり、自動でランダムな敵を攻撃する。スキルを受けデバフが解除される時、「怒噪」状態の解除が優先される。

<a id="enemy-term-be25171f6336"></a>

**共鳴**

共鳴状態。自身のスキル効果以外の行動順変化効果を受けない。この状態で弱点撃破される時、味方全体の行動順が早まる。

**別の状態説明**

共鳴状態。自身のスキル効果以外の行動順変化効果を受けない。この状態の時、削られる靭性値+<span style="color: #f29e38ff;" markdown="span">○○%</span>。弱点撃破される時、味方全体の行動順が早まる。

## ストーリー

「紅月」の転移によって死しても絶えぬ呼雷。飛霄の姿として現れ、鏡のように本人と相対する。

**業火焚心の影将軍**

「紅月」の影響を受けた飛霄は巨獣を従え、その神々しい姿の一挙手一投足に恐ろしい力が滲み出ている。
