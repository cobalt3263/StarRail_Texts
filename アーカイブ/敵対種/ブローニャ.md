### スキル

**ブローニャ**

| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | 疾風の弾丸 | 指定した味方単体に風属性ダメージを与える。 |
| スキル | 作戦再展開 | ブローニャ以外の指定した敵単体のすべての[デバフ](#enemy-term-0bae9566d833)を解除し、即座に行動させる。 |
| スキル | 増援協力 | 「シルバーメイン・近衛」または「シルバーメイン・狙撃手」を召喚する。 |
| スキル | 制圧射撃 | 指定した味方単体に風属性ダメージを与え、攻撃を受けた味方の行動順を遅らす。 |

<a id="enemy-term-0bae9566d833"></a>

**デバフ**

戦闘に不利な効果をもたらす持続状態。特殊な説明がない限り解除可能。

| 項目名 | 名前 | 説明 |
| -- | -- | -- |

<a id="enemy-term-4ac9a0693188"></a>

**速度**

速度は、ユニットの2回の行動の間隔に影響する。速度値が高いほど、間隔は短くなる。  
速度は、戦闘に入る時の行動順にも影響する。

<a id="enemy-term-acddd2e3a3f6"></a>

**戦闘不能状態**

味方の残りHPが0になるとこの特殊状態に入る。この状態のキャラは戦闘を続けることができない。

## ストーリー

ベロブルグ守護者の後継者、シルバーメインの最高司令官。  
ブローニャは多様な戦略で敵を攻撃し、味方の作戦能力を大アップする。

**ブローニャ（スペック）**

コードが影響を受けた後の正常な投影。ベロブルグ守護者の後継者、シルバーメイン（スペック）の最高司令官を参考にしている。  
ブローニャは多様な戦略で敵を攻撃し、味方の作戦能力を大アップする。

**ブローニャ（幻像）**

ベロブルグ守護者の後継者、シルバーメインの最高司令官。  
ブローニャは多様な戦略で敵を攻撃し、味方の作戦能力を大アップする。ここに現れたのはあなたの記憶をもとにシミュレートされた幻である。
