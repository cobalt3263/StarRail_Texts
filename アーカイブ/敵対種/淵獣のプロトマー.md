### スキル

**<ruby>淵獣<rp>（</rp><rt>えんじゅう</rt><rp>）</rp></ruby>のプロトマー**

| 項目名 | 名前 | 説明 |
| -- | -- | -- |
| スキル | 迎撃型捕食行動 | 味方全体に少量の風属性ダメージを与える。 |
| スキル | 飢餓の息 | 指定した味方単体および隣接するターゲットに風属性ダメージを与え、高確率で「<ins>[獣毒](#enemy-term-28c436c22e8f)</ins>」状態にする。 |
| スキル | 原初の聖餐 | 味方全体に少量の風属性ダメージを与え、「<ins>[獣毒](#enemy-term-28c436c22e8f)</ins>」状態の味方を「<ins>[麻痺](#enemy-term-f8735f027a42)</ins>」状態にする。 |
| スキル | 発光ルアー | チャージ状態に入り、次のターンで「原初の聖餐」を発動する。 |

<a id="enemy-term-28c436c22e8f"></a>

**獣毒**

与ダメージがダウンし、必殺技を発動できない。自身が愉悦スキルを発動した時、または「淵獣のプロトマー」が弱点撃破された時に解除され、自身が即座に行動する。

<a id="enemy-term-f8735f027a42"></a>

**麻痺**

この状態になるとEPが減少し、一定ターンの間行動できなくなる。

## ストーリー

「貪慾」のおとりの餌であり、「貪慾」の根源に限りなく近い創造物。怪しげなダンスと身を焦がす吐息で、生き物を抗えぬ幻惑へと誘い込み、古獣の腹を満たす餌食となるまで決して逃がさない。
