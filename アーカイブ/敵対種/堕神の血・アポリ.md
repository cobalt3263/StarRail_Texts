<a id="enemy-term-4ac9a0693188"></a>

**速度**

速度は、ユニットの2回の行動の間隔に影響する。速度値が高いほど、間隔は短くなる。  
速度は、戦闘に入る時の行動順にも影響する。

<a id="enemy-term-40ce553c91bf"></a>

**愉悦ダメージ**

カウントされた爆笑ネタが多いほど、愉悦度、キャラのレベルが高いほど、与える愉悦ダメージが高くなる。  
愉悦ダメージはダメージアップ系効果の影響を受けない。

<a id="enemy-term-7dacba0c891c"></a>

**堕神の衰腐**

スキルを発動するたびに1層減少し、一定の層数に達するとキャラは「幻怪」状態になる。継続時間が終了する、またはHPが0になる攻撃を受けると「幻怪」状態が解除される。「幻怪」状態の味方キャラとその召喚物は一時<ins>離脱</ins>する。同時に「狂獣の胚芽」を召喚し、一時離脱した味方キャラの代わりに戦闘を継続させる。「狂獣の胚芽」は味方キャラとして扱われる。

<a id="enemy-term-4c6db1d5f87e"></a>

**源質吞み**

回復できる最大HPがダウンする。この効果は累積できる。

<a id="enemy-term-b8d263dbe9f0"></a>

**ロックオン**

敵の「狂獣の胚芽」に優先的に攻撃ターゲット目標としてロックオンされる。

## ストーリー

博識学会を裏で操る技術開発部の主務は、脆弱な人間の肉体を捨て、その意識を巨大な「樹状脳」へと移した。ただ古獣の神秘を探るためだけに。  
人間の力を超越しようとするアポリの執念は、やがて彼女自身を終末へと導いた。完全に「貪慾」と同化された彼女の姿は胚胎にまで遡り、名状しがたい化け物へとなり果てたのだ。
