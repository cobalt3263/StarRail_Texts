# じゃんけん

**選択肢**

- **【巡狩】星体計算の※脆弱性※をするどく察知する**

  戦闘に入り、強化後の★1~2の祝福を1つ獲得する。

- **【記憶】その規則を思い出した！先にチョキを出す！**

  1. 確率で★2の祝福をランダムで2個獲得する
  2. すべての不利奇物を放棄する。（階差宇宙）
  3. 確率で★2の祝福をランダムで3個獲得する（階差宇宙）

**模擬宇宙**

> 目の前で天体計算機が高速で計算をしている。コンピューターの上半身は曲面のモニターで、下半身は性別がない人間の身体。大質量の恒星の崩壊をシミュレートしているように見えるが、今行っている駆け引きが、ただのじゃんけんだと知っているのはあなただけ。

**模擬宇宙**

> 「82.49%の確率であなたは最初の勝負でグーを出し、94.61%の確率で2回目にチョキを出します」天体計算機は喋る、「もし今、ちゃぶ台をひっくり返し、私が生成したモンスターと戦うのなら、99.37%の確率であなたは負けます」

**模擬宇宙**

> 「もし宇宙の欠片を残していくのなら、100%の確率で生還できます」計算機はあなたの反応を待つ。

- **天体計算機の「弱点」を鋭く察知する**

  1. もっと危険なほうの弱点を破る！戦闘に入り、勝利後に強化後の★1～2の祝福を2個獲得する（模擬宇宙 / 階差宇宙）
  2. もっと危険なほうの弱点を破る！戦闘に入り、勝利後に所持しているコンポーネントを2個獲得する（不可知域）
  3. もっと危険なほうの弱点を破る！戦闘に入り、勝利後に強化済みの★1～2の祝福を2個、奇物を1個、宇宙の欠片を100個獲得する（階差宇宙）
  4. もっと危険なほうの弱点を破る！戦闘に入り、勝利後に強化済みの★1～2の祝福を1個、奇物を1個、宇宙の欠片を50個獲得する（階差宇宙）

- **スクリューガムに「ハードディスク」の解体方法について助けを求める**

  戦闘に突入し、勝利後にチートのチャンスを1回獲得する

- **0.63%の確率のために戦う**

  戦闘に突入する

- **100%の安心感を選ぶ**

  宇宙の欠片×100を失う
