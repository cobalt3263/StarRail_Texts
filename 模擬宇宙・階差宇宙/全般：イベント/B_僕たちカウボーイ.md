# 僕たちカウボーイ

[イベント一覧へ](README.md) · [全体の目次へ](../../README.md)


**模擬宇宙**

> 太陽が大地を焼く。あなたは草を口にくわえ歩く。向こうから屈強な男たちが寄ってくる――彼らは気ままに騒ぎを起こす強盗、その後ろに傭兵軍団がついている。

**模擬宇宙**

> 「俺たちは最後のカウボーイだ！」リーダーは腕を振り上げ叫ぶ。赤いトキの腕章は、彼らが既に王室に帰服していることを示している。彼らは「王族」強盗だと確信できる。

**模擬宇宙**

> 「金を置いていけ！都市建設には資金が必要だ、気前こそが最後のカウボーイ精神！」図々しい強盗だ。あなたは彼らを睨み、草を思いっきり噛み切った――

**選択肢**

- **【虚無】そのまま降参する**

  1. 宇宙の欠片を25%失い、「虚無」の祝福をランダムで2つ獲得する
  2. 宇宙の欠片を100個失い、すべてのキャラが残りHPを20%失い、★1～2の奇物を2個獲得する。（階差宇宙）
  3. 宇宙の欠片を100個失い、すべてのキャラが残りHPを50%失い、★1～2の奇物を1個獲得する（階差宇宙）

- **お金を払う**

  1. 宇宙の欠片を50%失う
  2. 宇宙の欠片を50%を失い、ランダムで4個の祝福を強化する（模擬宇宙）

- **彼らに本物の「カウボーイ」を見せてやる**

  1. 戦闘に突入する
  2. 戦闘に突入し、勝利後に宇宙の欠片を追加で400奪える（不可知域）
  3. 戦闘に突入し、勝利後に★1～2の祝福を2個、宇宙の欠片を250個奪える（階差宇宙）
  4. 戦闘に突入し、勝利後に★1～2の祝福を2個、宇宙の欠片を150個奪える（階差宇宙）
