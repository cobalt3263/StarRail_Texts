# 獣の群れ・貪慾の災厄

[イベント一覧へ](README.md) · [全体の目次へ](../../README.md)


**模擬宇宙**

> 廃墟になった星系の古城で、血に飢えた古代の巨獣の群れに遭遇した。熱気溢れる息づかいが顔にかかった…

**模擬宇宙**

> 彼らは突然変異をした可能性があることに気が付いた…その皮膚は金メッキの硬い殻に覆われ、突然変異の苦しみを受け続けているようだった。

**模擬宇宙**

> その巨獣と見つめ合った。巨獣のひげが上下に動き、数体の幼体を背後にかばっていることに気が付いた……

**選択肢**

- **【壊滅】彼らをまとめて「苦痛」から解放する**

  1. 強化された精鋭との戦闘に突入→★3祝福2個と奇物1個獲得
  2. 善意にもとづく（不可知域 / 模擬宇宙）

- **大人の巨獣の「見送り」をする**

  1. 強化された精鋭との戦闘に突入→★3の祝福1つと奇物を2つ獲得する
  2. 他の星なら何か方法があるかもしれない…（模擬宇宙）

- **幼獣が「自由になる」のを手伝う**

  1. 戦闘に突入し、勝利後に★1～2の祝福を2個、奇物を1個獲得する
  2. 戦闘に入り、勝利後に★2の祝福を1個獲得する（模擬宇宙）
  3. 戦闘に突入し、勝利後に★1のコンポーネントを3個獲得する（不可知域）
  4. 戦闘に入り、勝利後に★1～2の祝福を2個獲得する（階差宇宙）

- **大人の巨獣の「苦痛」をケアする**

  1. 戦闘に突入し、勝利後に★3の祝福を1個、ランダムな奇物を3個獲得する
  2. 戦闘に入り、勝利後に★3の祝福と奇物をそれぞれ1個獲得する（模擬宇宙）
  3. 戦闘に入り、勝利後に★2のコンポーネントを1個、★2のセプターを1台獲得する。（不可知域）
  4. 戦闘に入り、勝利後に★3の祝福を1個、奇物を3個獲得する（階差宇宙）
