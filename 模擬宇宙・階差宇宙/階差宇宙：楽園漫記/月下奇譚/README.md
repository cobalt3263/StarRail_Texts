## 天賦スキル

「カセット」で解放する。
「カセット」：「楽園漫記」のアイテム解放や強化に使用する、独特なゲームカセット。
> 「名前なんていらない、『カセット』でいい。たかがゲームぐらい、誰にだって作れるから」

**「不幸」**
- **人々の願い**
エリアに入った時、願力を30獲得する。1回の挑戦につき、ドローフェーズで合計2回引き直すことができる

- **喜笑**
味方の愉悦度+2%

- **人と神**
次元界Ⅱのボスに勝利した後、ランダムで2個のエリアのレベル+1

- **生きる**
仮面を選ぶ時、更新回数を1回獲得する

**「無意味」**
- **快楽**
味方の速度+2%

- **爆笑**
味方の会心ダメージ+3%

- **心の壁**
味方の防御力+3%

- **創造物**
非凡な奇跡の出現率がアップする

**「時間」**
- **成長**
次元界Iのボスに勝利した後、ランダムで2個のエリアのレベル+1

- **俗世にて**
奇跡を選択する際、1ゲームにつき、引き直しが3回できる

- **子供時代**
次元界Iに入った時、宇宙の欠片を追加で20獲得する

- **運命**
稀な奇跡の出現率がアップする

**「退屈」**
- **ユーモアセンス**
味方の会心率+2%

- **覆水盆に返らず**
味方の効果命中+3%

- **イエスマンになるな**
味方の効果抵抗+3%

- **堕落**
次元界Ⅱに入った時、願力を25獲得する

**「郷愁」**
- **旅立ち**
味方の受けるダメージ-2%

- **忘却**
味方の撃破特効+3%

- **帰路に立つまで**
味方の与ダメージ+3%

- **倒影**
次元界Ⅲに入った時、願力を25獲得する

**「自我」**
- **私は誰**
次元界Iのボスに勝利した後、★1～2の奇物を1個獲得する

- **私はどこから来た**
味方の攻撃力+3%

- **どこへゆく**
初期の引き直し回数+2

- **我ら**
初期の引き直し回数+1
