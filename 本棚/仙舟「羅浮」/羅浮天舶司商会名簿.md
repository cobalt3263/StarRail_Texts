# 羅浮天舶司商会名簿

[仙舟「羅浮」の書籍一覧へ](README.md) · [本棚へ](../README.md) · [全体の目次へ](../../README.md)

> 天舶司の商会目録。羅浮の商会の運営範囲を記録してある。

- 星槎海中枢

---

現在、羅浮天舶司に所属する商会には鳴火、天駆、乗軒、流金、素羽、暉夜、翔水の7社があります。  
域内外のビジネス人脈と羅浮天舶司商会との交渉の便宜のために、各商会の接渡使および経営範囲を以下に列挙します。

<span style="font-size: 1.5em;" markdown="span">鳴火商会</span>  
<strong>接渡使：</strong>停雲  
<strong>経営範囲：</strong>各種加工品関連の輸出入貿易

鳴火商会は銀河の中で最も速く、最も安全な生物輸送艦を保有しています。工業原材料以外にも、商会は農畜産物の育種や改良業務を請け負っており、生物資源の豊富な星からの問い合わせを心から歓迎しています。

<span style="font-size: 1.5em;" markdown="span">天駆商会</span>  
<strong>接渡使：</strong>岩明  
<strong>経営範囲：</strong>芸術品、出版物等の各種文化製品の輸出入貿易

天駆商会は各種文芸商品の貿易を請け負っています。仙舟における域外文化に関する展示会やイベントの開催、および域外における各種の羅浮文化に関する展示会やイベントの開催については、天駆商会までご相談ください。

<span style="font-size: 1.5em;" markdown="span">乗軒商会</span>  
<strong>接渡使：</strong>長慶  
<strong>経営範囲：</strong>各種武器および軍需品関連の輸出入貿易

乗軒商会は軍需品の貿易を請け負っています。同盟の使命<strong>は</strong>、正しい自然秩序を維持し、豊穣の忌み物を取り除くことにあります。軍事技術製品の輸出については、必ず天舶司の審査を受けてください。

<span style="font-size: 1.5em;" markdown="span">流金商会</span>  
<strong>接渡使：</strong>昌文  
<strong>経営範囲：</strong>各種医薬品関連の輸出入貿易

流金商会は医薬健康製品の輸出入を請け負っています。『天舶司貿易管理条令』の関連規定に基づき、貿易ホワイトリストに含まれていない医薬品はすべて検査を受ける必要があり、違反者は羅浮との交易を厳禁されます。

<span style="font-size: 1.5em;" markdown="span">素羽商会</span>  
<strong>接渡使：</strong>致尭  
<strong>経営範囲：</strong>各種星槎関連の輸出入貿易。

素羽商会は星槎の輸出の他、星槎の外観デザインのアフターサービスも提供しており、異なる生活シーンや文化環境に合わせて改装を行っています。

<span style="font-size: 1.5em;" markdown="span">暉夜商会</span>  
<strong>接渡使：</strong>蘊霊  
<strong>経営範囲：</strong>仙舟同盟内部の各種貿易。

暉夜商会は各地の特産品を羅浮に集積しています。朱明の磁器、方壺の水産物、玉殿の玉兆など、仙舟の他地域からの物産品は何でもそろっています。

<span style="font-size: 1.5em;" markdown="span">翔水商会</span>  
<strong>接渡使：</strong>仲初  
<strong>経営範囲：</strong>各種非主要商品（農業副産物、化学工業原料、紡績原料など）の輸出入貿易

翔水商会はほぼすべてのタイプの貿易業務を請け負っています。極めて巨大な艦隊を有し、羅浮の7つの商会の中でも最大規模の1社です。
